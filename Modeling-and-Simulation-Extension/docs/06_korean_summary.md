# 모델링·시뮬레이션 후속 연구 (한국어 요약)

이 폴더는 [기존 버지니아주 캡스톤](../../README.md)에서 분석했던 **소득 불평등과 패스트푸드 매장 밀도의 관계**를 동적인 확률 모델로 확장한 후속 연구입니다.

## 기존 연구에서 확인된 결과

기존 [결과 문서](../../paper/06-results.md)는 지니계수와 인구 1만 명당 패스트푸드 매장 밀도 사이에서 **약하지만 통계적으로 유의한 양의 상관관계**를 보고합니다.

- 피어슨 상관계수: **0.2095**
- 회귀식: **밀도 = −4.377 + 23.939 × 지니계수**
- 유의확률 p = **0.0181**, 결정계수 R² = **0.0439**
- 중위 가구소득과 매장 밀도: 유의하지 않음(p = **0.380**)
- 매장 밀도와 성인 비만율: 유의하지 않음(p = **0.566**)

회귀의 설명력이 약 4.4%이므로, 원본 연구는 소득 불평등만으로 매장 분포 전체를 설명하지는 못합니다.

## 후속 연구의 핵심 변화

정적인 상관관계를 관찰하는 데서 나아가 다음 식을 이용한 120단계 시뮬레이션을 구성했습니다.

$$F_{t+1}=(1-\beta)F_t+\alpha G+\epsilon_t$$

실제 코드는 음수 밀도를 0으로 제한합니다. F는 인구 1만 명당 매장 밀도, G는 고정 지니계수, α=3.59는 불평등 관련 입력 계수, β=0.15는 시장 제약·감쇠 계수, ε는 확률적 변동입니다. **120단계는 실제 120년이나 120개월을 뜻하지 않습니다.**

이론적 균형은 **F* = (α/β)G**입니다. α/β ≈ **23.933**으로 원본 회귀계수 **23.939**와 거의 같지만, 기존 회귀의 절편 **−4.377**은 반영하지 않았습니다. 따라서 기울기가 유사하다는 사실만으로 모델이 현실에서 검증된 것은 아닙니다.

## 네 가지 실험 결과

1. **불평등 시나리오:** G=.35/.45/.55에 따른 이론적 균형 밀도는 각각 **8.377/10.770/13.163**입니다.
2. **균형 분석:** 이 모델에서 G가 높을수록 밀도가 높게 설정되며, 이는 가정한 수식의 결과입니다.
3. **민감도 분석:** β가 증가하면 이론적 밀도는 **역비례** 형태로 감소합니다. 지수적 감소는 아닙니다.
4. **가상 정책 충격:** 50단계에서 β를 0.15→0.30으로 변경하면 이론적 균형은 **10.770→5.385 (−50%)**가 됩니다. 실제 규제 효과를 추정한 값은 아닙니다.

## 추가 보완

원본 논문에서는 난수 시드 42를 한 번 사용했습니다. G=.45, β=.15 설정의 마지막 30단계 평균은 **8.065**로 이론값 **10.770**과 차이가 있습니다. 보완 코드로 1,000회 반복 실험을 실행한 결과, 실행별 마지막 30단계 평균을 다시 평균한 값은 **약 10.699**였습니다. 이는 모델 내부의 확률적 변동에 관한 점검이며 **실제 버지니아주 관측자료 검증이 아닙니다**.

## 연구의 의의

기존 캡스톤의 관측 데이터 분석을 출발점으로 삼아 가정을 수학적 형태로 명시하고, Python을 활용해 시간에 따른 변화, 시장 제약의 민감도, 가상 정책 충격을 실험했습니다. 통계적 **상관관계**와 모델에 가정한 **동적 인과 메커니즘**을 엄격히 구분하는 것이 중요합니다. 상세 내용은 [확장된 영문 논문](05_revised_paper.md)과 [한계 분석](04_validation_and_limitations.md)을 참고하세요.
